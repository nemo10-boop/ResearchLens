# 🔬 ResearchLens — AI Research Paper Summarizer

An AI-powered tool that analyzes multiple engineering research papers,
summarizes findings, compares them, and identifies research gaps.

## Features
- Upload 2–6 research papers (PDF)
- AI-generated summaries for each paper
- Cross-paper comparison
- Research gap identification
- Thesis topic suggestions

## Built With
- Python + Streamlit
- Google Gemini API (gemini-2.5-flash)
- PyMuPDF (PDF parsing)
